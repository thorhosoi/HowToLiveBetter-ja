# 高コスパ人生ガイド

長生きして病気を減らす方法、事故が起きたときの助け方。無駄なお金を減らす方法、だまされたり訴訟に巻き込まれたりしやすいこと。仕事もお金もないときに何がもらえるか、店・会社・ウェブサイトを始めるのにどんな手続きが要るか。恋愛・結婚・出産、海外渡航、手に職をつける話も扱います。<br>
631 項目の提案それぞれに、何を払い、何が戻り、証拠がどれだけ固いかを書きました。出典は学術論文と公的文書だけです。

全部やる必要はありません。これはコスパ順に並べた選択肢のリストで、タスクリストではありません。1つか2つ拾えば十分です。著者自身も、大半はできていません。

## 読み方

- **全部やる必要はありません**：これはコスパ順に並べた選択肢のリストで、タスクリストではありません。1つか2つ拾えば十分で、残りは置いておき、必要になったときに調べに戻ってください。「言うは易く行うは難し」という評価は正しく、著者自身も大半はできていません。必要なときに見つかるように書いてあります。手間の少ないものを選びたい人は、下の「いちばんやる価値があるものだけ見たい」を見てください。
- **AI に調べてもらいたい**：リポジトリには中国語の skill（[skills/life-decision-guide](../skills/life-decision-guide/)）が入っていて、Claude Code と Codex のどちらにも入れられます。入れたあとで「友人の保証人になるべきか」「毎日の通勤 2 時間は割に合うか」と聞くだけです。まず本文から関連する項目を調べ、本のとおりの計算方法で並べ替えて答え、第何節の第何条かも示します。見つからなければ見つからないと言い、数字を作ることはしません。入れ方は [そのディレクトリの説明](../skills/life-decision-guide/README.md) を見てください。
- **条件で選びたい**：[オンライン検索ページ](https://eternity4719.github.io/HowToLiveBetter/)を開くと、キーワード、章、エビデンスレベルで絞り込めます。「お金がかかるか、どれだけ時間がかかるか、根気が要るか」の3つでも絞り込めて、複数の条件を重ねられます。ページの内容は book/ ディレクトリの本文をそのまま取っているので、本文が変わればページも変わります。
- **項目どうしは互いに案内しあっています**（「第 8 節第 17 条を見よ」のような形）：検索ページでは、この案内に点線が付きます。押すと、指されている項目のタイトルと「ひとことで言うと」がその場で表示されます。実際にそこへ移りたいときは、「ジャンプ」を押します。その項目がちょうど絞り込み条件で隠れていた場合は、ページが自動で絞り込みを解除します。GitHub 上で本文を読む場合は押せませんが、案内のあとに何を指すかが書いてあります（「第 18 条（借用書をきちんと書く）を見よ」）。移らなくても、どの項目のことかは分かります。
- **順番に読みたい**：各節の項目はコスパの高い順に並んでいます。各節の最初の数条から読めば足ります。
- **オフラインで読みたい、人に送りたい**：[オフライン単一ファイル HTML](https://github.com/eternity4719/HowToLiveBetter/releases/download/epub-latest/HowToLiveBetter.html) をダウンロードしてください。本全体が、検索や絞り込みも含めてこの1ファイルに入っています。ダブルクリックで開き、サーバーもネット接続も要りません。WeChat でもそのまま送れます。
- **印刷したい、スマホでめくりたい**：[PDF](https://github.com/eternity4719/HowToLiveBetter/releases/download/epub-latest/HowToLiveBetter.pdf) をダウンロードしてください。A4 判で 200 ページ以上あり、目次のページ番号としおりが付き、節ごとに改ページします。
- **Kindle などの端末で読みたい**：[EPUB 電子書籍](https://github.com/eternity4719/HowToLiveBetter/releases/download/epub-latest/HowToLiveBetter.epub) をダウンロードしてください。Kindle では Send to Kindle で送れば足ります。
- **この3つは、本文が更新されるたびに自動で作り直されます**。ダウンロードのリンクは変わりません。転送したものは更新されないので、オンライン版を基準にしてください。
- **数字が読めない**：どの項目にも「ひとことで言うと」という行があります。「効果」欄にある研究の書き方を、「同じ期間に亡くなる確率が約 2 割低い」「何日拘留され、いくら罰金か」のような日常の言い方に直したものです。「効果」欄にすでに書いてある内容しか使わず、新しい数字は足しません。この1行だけ見れば判断できます。「効果」欄には数字がすべてそのまま残してあるので、自分で確かめたいときはその欄を見てください。
- **いちばん結論が固いものだけ見たい**：検索ページでエビデンスレベル A にチェックを入れると、具体的な数字があり、メタアナリシスや大規模な試験に基づく 421 項目だけが残ります。
- **いちばんやる価値があるものだけ見たい**：コスパ「極めて高い」にチェックを入れると 108 項目が出ます。お金も時間も根気も要らず、効果がいちばん大きい段階に入る項目です。さらに「何が戻るか」を重ねれば、その基準での優先リストになります。
- **「〜しない」で始まる節の題に身構えなくて構いません**：節の題が言っているのは、その節が防ごうとしていること（早死にしない、時間を無駄にしない）で、下の各項目が全部「やめろ」と言っているわけではありません。実際にやる動作は項目の題に書いてあり、すべて動詞で始まります。「する」のか「しない」のかは、それだけで分かります。同じ節に両方あります。第 4 節には「『やるつもり』を『何時に、どこで、何が起きたら何をする』に書き換える」もあれば、「テレビを見ない、ニュースをスクロールしない」もあります。節の題の語気に合わせず、項目の題のとおりに読んでください。

各項目はこんな形をしています。

```markdown
### 5. 把家里的食盐换成低钠盐（钾盐）
- 成本：一袋比普通盐贵几元。买的时候顺手换，不额外占时间。口味几乎不变。
- 说人话：两万人的随机试验里，把家里的盐换成低钠盐的人，五年内死亡的概率低约 12%，中风低约 14%。这是随机分成两组比出来的，比只跟踪记录得到的数字更可信。
- 收益：一项把人随机分成两组的试验，在中国农村做的，20995 人，都是得过卒中的人或者 60 岁以上的高血压病人，跟踪了 4.74 年。结果：用低钠盐的那组比用普通盐的那组，死亡风险低约 12%（RR 0.88）。卒中低约 14%（RR 0.86）。主要心血管事件低约 13%（RR 0.87）。
- 证据等级：A
- 来源：Neal B 等 (2021). Effect of Salt Substitution on Cardiovascular Events and Death. NEJM. https://doi.org/10.1056/NEJMoa2105675
- 备注：争议。试验对象是高危老人，健康年轻人换盐得到的好处要小得多。肾功能不全的人，或者正在吃保钾类药物的人，换盐前先问医生。
```

> 訳注：上は原文（中国語）の項目形式をそのまま示したものです。日本語版では「成本」を「コスト」、「说人话」を「ひとことで言うと」、「收益」を「効果」、「证据等级」を「エビデンスレベル」、「来源」を「出典」、「备注」を「備考」と訳します。

自分のパソコンやサーバーで本当に動かす場合：

```bash
git clone https://github.com/eternity4719/HowToLiveBetter.git
cd HowToLiveBetter
python -m http.server 8000
```

そのあとブラウザで `http://localhost:8000/` を開きます。検索ページは純粋な静的ページで、`README.md` と `book/` がそのままデータです。バックエンドもデータベースもなく、依存ライブラリのインストールも要りません。ディレクトリ全体を任意の静的サーバー（Nginx、GitHub Pages、オブジェクトストレージ）に置けば、同じように動きます。注意：`index.html` は必ず http 経由で開いてください。ローカルのファイルをダブルクリックして直接開くと白紙になります。ブラウザがウェブページにローカルファイルを読ませないためで、その場合は上のオフライン単一ファイル版を使ってください。

3種類の電子版を自分で生成したい場合（普段は不要で、Release にあるものが自動生成されたものです）：

```bash
cd tools/epub && npm ci && npm run build   # EPUB
node tools/offline/build.mjs               # オフライン単一ファイル HTML
node tools/pdf/build.mjs                   # PDF。別に pandoc ≥ 3.1 と typst ≥ 0.13 が必要
```

生成物はすべて `dist/` に出ます。

## 4種類の資源

この本が余分に残したいのは寿命だけではなく、全部で4つあります。

- **寿命**：長く生きる。避けられたはずのことで死ぬのを減らす
- **時間と気力**：生きている時間を見返りのないことに使わない。毎日の注意力と体力を無駄に削らない
- **お金**：無駄な出費を減らし、効果が確かなところにお金を使う
- **身体の自由**：1つのレッドラインを知らなかったせいで、拘留所や留置場に入ることのないようにする

どの提案も2つの問いに答えます。何を払うか（お金・時間・気力・根気）、何が戻るか（総死亡率の変化 / 特定の死因の減少 / 時間と気力の節約 / お金の節約 / 保障と身体の自由）です。項目はコスパ順に並べ、分野順ではありません。ほとんどコストがかからず、戻る利益が大きいものを、いちばん前に置きました。

**1つの提案の利益が誰に落ちるかは、段階に分かれています。**「この利益が将来、自分自身に戻ってくる見込みがどれだけあるか」で、高い方から並べます。① **自分自身**。② **配偶者と直系親族**（父母、子、祖父母・外祖父母、孫・外孫）。③ **友人、同僚、その他の親族**。互いに助け合う関係なので、助けたものが将来戻ってくることがあります。④ **見知らぬ人**。いちばん低い段階ですが、ゼロではありません。見返りの確率は小さく、相手の性格も分からず、言いがかりをつけられたり、逆に咬みつかれたり、報復されたりする面もあります。段階の違う利益は合算しません。第 ④ 段階について書くときは、利益とリスクを一緒に書きます。

救急の節はこう読んでください。中国の院外心停止 38,227 例のうち 79.2% は自宅で起きています。胸骨圧迫を学ぶのは、まず自分の家族に使うためです。「溺れている人を見ても自分は水に入らない」「殴り合いに出くわしても手を出して止めない」といった規則そのものが自分を守る規則で、傍観者から2人目のけが人にならないためのものです。見知らぬ人に手を貸すかどうかは、自分で比べて決めることです。項目には免責の規定、身を守る動作、リスクの面をすべて書いてありますが、それを「やらなければならない理由」に数えることはしません。

死亡率の数字、時間と気力の数字、お金の数字、法的な結果は、それぞれ別に数え、互いに換算しません。この4つは、検索ページの4つの「何が戻るか」に対応していて、互いに大きさを比べません。

## エビデンスレベル

どの提案にもエビデンスレベルを付けています。

| レベル | 意味 |
| --- | --- |
| A | 調べられる具体的な数字がある。出典は、複数の研究をまとめたメタアナリシス、たくさんの人を長年追跡した大規模コホート、またはランダムに分けた試験（RCT）で、どれだけ下がったか（HR、RR、低下のパーセント）を示せる |
| B | 研究の裏付けはあるが、確かな数字は示せない。または、小さな標本か1つの研究だけが支えている |
| C | 著者自身の経験か、皆が認めているやり方で、直接の研究文献はない |

全 631 項目のうち A 級が 421 項目、B 級が 159 項目、C 級が 51 項目です。ほかに 58 項目に「論争あり」を付け、34 か所に TODO（要確認）を付けています。論争のある A/B 級の項目には「論争あり」を付け、反対側の証拠を並べます。出典は一次文献だけです（学術論文は DOI か PubMed のリンクを付け、WHO、CDC、国家統計局などの公的機関の報告も可）。二次的な引用は使いません。確かでない数字には「要確認」と付けます。

## コスパの段階

エビデンスレベルが答えるのは「この数字は信用できるか」だけで、「これはやる価値があるか」には答えません。そこで各項目にはもう2つ付けています。効果の大きさ（利益がどれだけ大きいか）と、基準（何が戻ってくるか）です。検索ページはこの2つと3つのコストを合わせて、コスパの段階を出します。

| 観点 | 値 | 決め方 |
| --- | --- | --- |
| 基準 | 寿命を得る / お金を得る / 時間と気力を得る / 身体の自由を得る | この項目が主に何を取り戻すかを見る。**異なる基準どうしは比べない**。「総死亡率が 12% 下がる」と「毎年 500 元浮く」は同じ物差しに乗らず、優劣を付けられない |
| 効果の大きさ | 大 / 中 / 小 | できるだけ項目自身の「効果」欄に従い、あらかじめ決めた境界線を当てはめる。感覚では決めない。寿命は何パーセント下がったかを見る（20% 以上は大、10–20% は中、10% 未満、または中間の指標しか測れず最終結果を測れていないものは小）。お金は金額を見る（万元単位は大、数百から数千は中、数十は小）。身体の自由は結果を見る（刑事責任を避けられるなら大、拘留や行政処罰を避けられるなら中、民事上の争いを避けられるなら小）。時間と気力は節約量を見る（毎日 1 時間単位で浮くなら大、毎週 1 時間単位なら中、1 回だけなら小） |
| コスパ | 極めて高い / 高い / 一般 | 利益が大きく、3つのコストがすべてゼロ = 極めて高い。利益が大きく、コストが高くない、または利益が中で、コストがゼロ = 高い。残り = 一般 |

全 631 項目のうち、コスパ極めて高いが 108 項目（17%）、高いが 289 項目（46%）、一般が 234 項目（37%）です。真ん中の段階の項目数が多いのは意図的です。土台の効果の大きさが大・中・小の3段階しかないので、これ以上細かく切ると、精密なふりをすることになります。

**この段階は著者自身の判断であり、証拠ではありません。** この本の基準では、それ自体は C 級にしかなりません。エビデンスレベルとは別のもので、互いに影響しません。ある項目はエビデンスが A 級でも、コスパは一般ということがあります（帯状疱疹ワクチンは有効率 97.2% という第 3 相 RCT があるものの、2 回接種で 3 千〜4 千元かかり、帯状疱疹で亡くなることはめったにない）。逆に、エビデンスが C 級しかなくても、コスパが極めて高いことがあります（出国前に日程を家族に送る）。「一般」は、やらなくてよいという意味ではありません。本の項目はすべてやることを勧めていて、この段階は、その出費が見合うかを自分で量る必要がある、というだけです。

## 数字の読み方（用語集）

本文はできるだけ日常の言い方にしていますが、研究を引くときは、いくつかの統計用語がどうしても出てきます。分からなければこの表を見てください。オンライン検索ページでは、点線の付いた語にマウスを置く（スマホでは1回押す）と、説明が出ます。

<details>
<summary>41 の用語を開く（総死亡率、HR、RR、95% CI、メタアナリシス、BMI、LPR、定金と訂金……）</summary>

| 用語 | 意味 |
| --- | --- |
| 総死亡率 | ある期間に、あるグループのうち亡くなった人が何割か。死因は問わない。この本では「長生きできるか」を測るのに使う。研究の原文では全死因死亡率と呼び、英語の略称は ACM |
| HR | ハザード比。同じ期間に、ある行動をしたグループが、していないグループに比べて、悪いこと（死亡、発病）に至る速さを、割り算で比べたもの。HR 0.87 なら、していないグループより 13% 低く、HR 1.21 なら 21% 高い |
| RR | 相対リスク。2つのグループの、悪いことが起きる可能性の比。数字の読み方は HR と同じ |
| OR | オッズ比。これも2つのグループの比較だが、計算のしかたが RR と少し違う。比べる出来事がまれなときは RR とほぼ同じで、よくあることのときは、実際より差を大きく見せる |
| IRR | 発症率比。発症率とは、ある期間に新しくその病気になった人の割合で、2つのグループのものを割り算する。読み方は RR と同じ |
| RaR | 発生回数の比。悪いことが何回起きたか（たとえば何回転んだか）を比べるもので、何人がそうなったかではない。読み方は RR と同じ |
| 標準化死亡比 | 英語の略称は SMR。このグループで実際に亡くなった人数を、「同じ年齢の普通の人ならこれだけ亡くなるはず」の人数で割ったもの。5.86 なら、亡くなった人数が同年齢の人の 5.86 倍 |
| リスク差 | 2つのグループの、悪いことが起きる確率を引き算し、「1000 人につき何人多いか」をそのまま出したもの。倍率は何倍になったかしか言わないが、リスク差は実際に何人増えたかを言う |
| 95% CI | 95% 信頼区間。研究で出した数字には必ず誤差があり、これは本当の状況がおそらく収まる範囲。倍率の数字では範囲が 1 をまたぎ、足し引きの数字では範囲が 0 をまたぐと、2つのグループの差はたまたまかもしれないことになり、文中では「統計学的に有意でない」と書く |
| RCT | ランダム化比較試験。くじ引きのような方法で人を2つのグループに分け、一方はそのことをし、他方はしない。あとで結果がどれだけ違うかを比べる。「そのことが効いた」と証明するには、この方法がいちばん説得力がある |
| メタアナリシス | たくさんの研究の結果を集めて計算し直し、全体としての1つの数字を出したもの。meta 分析とも言う |
| コホート | コホート研究。大勢の人を選んで長年追跡し、誰に悪いことが起きたかを記録する。2つのことがよく一緒に現れると分かるが、前のことが後のことを起こしたとまでは言えない |
| 観察研究 | 研究者が横で記録するだけで、誰にやらせ誰にやらせないかは決めない。他の要因に結果を引っ張られやすい（この表の交絡と逆の因果の2項目を参照）。数字は少し割り引いて見る |
| 交絡 | 第三の要因が原因と結果の両方に同時に働いて、2つのことに因果があるように見せる。たとえば、野菜が好きな人は運動も好きなことが多く、どちらが効いているのか分けられない |
| 逆の因果 | 因果の向きが逆になっている。前のことが後のことを起こしたように見えて、実は後のことが前のことを起こしている。寝る時間が長いから早死にするのではなく、重い病気の人ほど長く寝ている |
| d、g | 効果量。2つのグループの差がどれだけ大きいかを表す。差を「ふだんのばらつきの幅の何個分か」に換算したもの。0.2 が小、0.5 が中、0.8 が大 |
| r | 相関係数。2つのことが一緒に変わる密接さで、-1 から 1 までの値をとる。0.1 は弱く、0.3 は中程度、0.5 は強い |
| MET | 運動の強さの単位。静かに座っているのが 1 MET、速歩きが約 3〜4 MET。MET·h と書けば、強さに何時間やったかを掛けたもので、合計でどれだけ動いたかを表す |
| GRADE | 国際的に通用している採点の方法。1つの証拠がどれだけ信頼できるかを、高・中・低・非常に低の4段階で評価する |
| 割付け意図に基づく解析 | 効果を出すとき、「誰にスクリーニングを受けるよう通知したか」で数え、「誰が実際に受けたか」では数えない。通知された人の中には必ず受けなかった人がいるので、この計算は、実際に受けた人にとってのスクリーニングの利益を低く出す |
| パック・イヤー | 人が全部でどれだけタバコを吸ったかを数える単位。毎日何箱かに何年かを掛ける。30 パック・イヤーは、毎日 1 箱で 30 年吸ったということ |

| eGFR | 推算糸球体濾過量。腎臓のろ過能力を測る検査の項目で、単位は mL/min/1.73 m²。数が低いほど腎機能が悪く、慢性腎臓病が何期かはこれで決める |
