# 日本語訳の方針

`ja/` 以下の日本語版に適用する。中国語の原文は `book/*.md`、`README.md`、`docs/*.md`。
規約の骨格は dlgrv 氏の fork（EN/RU/ES、`TRANSLATION.md`・`QUALITY.md`・`translate/glossary.json`）を参考にした。

## 配置
- `ja/README.md`、`ja/book/NN-<日本語題>.md`、`ja/docs/<日本語題>.md`
- 章番号の2桁接頭辞は原文と同じ。ファイル名の題は日本語にする。
- 各ファイルの1行目に状態行を置く：
  `> 非公式訳。原文：[book/01-不要早死.md](../../book/01-不要早死.md)。食い違いがある場合は中国語の原文を優先する。`
- 状態行の直後に「訳出時点の原文コミット」を1行書く（本家メンテナーの依頼）。原文が更新されたら、訳を直したときにこのハッシュも更新する。
- 次の行に総目次への戻りリンク `[← 総目次へ](../README.md)`。

## 一字も変えないもの
- 条の番号と順序。条の統合・分割はしない（本文中の「第 X 節第 Y 条」が条番号で引用されているため）。
- エビデンスレベル A/B/C と、備考冒頭の「論争あり」（原文の「争议」）の判断。
- 「来源」行の中身（著者名・雑誌名・DOI・URL・中国の法令名と文書番号）。ラベルだけ訳す。
- 数値、HR/RR/OR/CI、パーセント、金額、年月日。
- 見出し直下のコメント `<!-- 成本标签: ... -->`。値もフィールド名も原文とバイト単位で同一にする。検索ページがこれを読む。
- Markdown の構造（見出しの階層、`### N.` の番号、項目の順序、リンク）。

## 訳すもの
| 原文 | 日本語 |
|---|---|
| 成本 | コスト |
| 说人话 | ひとことで言うと |
| 收益 | 効果 |
| 证据等级 | エビデンスレベル |
| 来源 | 出典 |
| 备注 | 備考 |
| 争议（備考の書き出し） | 論争あり |
| 待核实 / TODO | 要確認 |

- 「ひとことで言うと」は最重要行。自然な話し言葉に訳す。「効果」欄に無い数字・事実・機序を足さない。
- 統計用語（HR、RR、OR、CI、RCT）は README の用語集で説明し、本文は原文どおり使う。「说人话」には出さない。
- 金額は人民元のまま。円換算はしない。六桁以上は「約 X 万元（正確な値 元）」、桁区切りのカンマは付けない（原文の規則）。
- 「性价比」は「コスパ（費用対効果）」に統一する。

## 文体
- です・ます調。感嘆符・説教口調は使わない。条の見出しは動詞で始める建議文。
- 1文1メッセージ。目安 40 字前後、最長でも 70 字。原文の「一遍で分かる」水準を保つ。
- 原文の限定・否定・条件・立場は内容なので落とさない。より断定的にも、より具体的にもしない。
- 疫学用語の直訳を避ける。例：コホート→「追跡調査」、交絡→「他の要因の影響」。ただしメタアナリシス、ランダム化比較試験、信頼区間は定着語としてそのまま使う。

## 中国固有の制度
- 制度名・機関名は日本語訳に中国語を添える。章内の初出のみ。例：最低生活保障（低保）、戸籍（户口）、公的医療保険（医保）。
- 法令名は日本語訳＋原名。例：労働契約法（劳动合同法）。条文番号は出典欄にあるものを使い、本文では動作を先に書く。
- 電話番号（12356、12308 など）は原文の値を残す。日本の 110/119 との対応は「訳注」でのみ足す。
- 訳者による補足は必ず `> 訳注：…` の形で見出しの下に置くか、初出の括弧書きに限る。原文の内容は書き換えない。
- 中国の法律・制度を引く節（8、9、11、15、19、25、26、31 ほか）は、見出しの下に一行入れる：
  「この節は中国の法律・制度を前提にしています。中国国外の読者にとっては参考資料であり、適用される法ではありません。」

## 品質基準（QUALITY.md を簡略化）
致命的（1つでも不合格）：
1. 数値・DOI・URL・出典行の改変または脱落
2. HR/RR/OR/CI の誤り
3. 成本标签コメントが原文と不一致
4. 原文に無い内容の追加
5. 状態行・戻りリンクの欠落、条数の不一致

重大：医学・法律用語の誤訳、章内での訳語の不統一。
軽微：文法、不自然な直訳、文体の乱れ。

## 検証
- 条数、成本标签コメント、出典行、数字列の一致を、原文と機械的に突き合わせる。dlgrv fork の `translate/steps/verify/verify.py` を参考に `ja/tools/verify.py` を用意する予定（未着手）。
- 訳注と括弧内の中国語併記は、数字・漢字の照合前に除去する。
